# Machine-Learning for Materials
Jupyter Notebooks for Teaching Machine Learning and Data Science in Materials Science

## Mechanical Engineering

[Physics-guided features: a cantilever surrogate](Notebooks/Mechanical_Engineering/Physics_Guided_Cantilever.ipynb)
compares regression using Young's modulus E and its reciprocal 1/E on ten
precomputed finite-element cases. Includes a loading schematic, fitted models,
held-out errors, and student exercises. Requires NumPy and Matplotlib only;
the data and provenance are included in the notebook.
